## 1. 화면 깨짐 점검

- 대상: 로그인(000000 + 111111) 후 환자 홈, 대장내시경·위험 신호·준비물·안내문 12개(+쉬운 설명), 확인 질문 12개, 또박이 선생님 수업 14장면, 약 확인 흐름 13단계 = 언어마다 69개 화면.
- 방법: 휴대폰 너비(390px)로 열어 글자 잘림, 화면 밖으로 나감, 글자끼리 겹침, 한글 남음, 같은 말 반복을 자동으로 찾고 화면 사진을 저장했다.
- 점검한 화면 사진: 작업 폴더(임시)에 저장함. 문제가 있던 화면만 아래에 적었다.

| 발견한 문제                                                                                              | 언어                        | 화면                              | 조치                                                                                                                                                               |
| -------------------------------------------------------------------------------------------------------- | --------------------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 음식 이름 칸에서 글자가 잘림 (예: 雑穀ご飯, 種のある果物, 白いご飯 白がゆ, Rong biển khô Rong biển canh) | 일본어·베트남어             | 또박이 수업 1~2교시, 음식 카드    | `photo-lesson.css`의 `.ld-name`에 줄바꿈(`overflow-wrap: anywhere`)을 추가했으나 단어 중간이 잘려 2026-10-30에 없앴다. 지금은 `fit-text.tsx`가 글자 크기를 줄인다. |
| 한글이 남음: 가소콜액 (Gasocol)                                                                          | 영어·일본어·중국어·베트남어 | 안내문 8번, 쉬운 설명, 수업 6교시 | 2026-10-30에 고쳤다. 외국어 화면에는 한글을 남기지 않고 `Gasocol`로만 쓴다(`translate.ts` 규칙과 `translations/*.json` 모두).                                      |
| 글자끼리 겹침·같은 말 반복                                                                               | 3개 언어                    | —                                 | 사진으로 확인되는 실제 문제는 없었다(자동 검사의 겹침 표시는 슬라이드·고정 막대 때문에 생긴 오탐).                                                                 |

참고: 자동 점검을 3개 언어 동시에 돌리면 한글이 남은 것처럼 나오는 오탐이 생겼다(서버가 느려서 번역이 늦게 적용됨). 한 언어씩 다시 돌렸을 때는 위 표의 한글 외에 남은 한글이 없었다.

## 3. 숫자·시간·양·약 이름 자동 검사

한국어 원문과 번역문의 숫자(시간·양·횟수)를 비교했다. 약 이름은 가소콜의 영문 표기 여부를 확인했다.

| 언어     | 문장 수 | 숫자가 다른 문장 | 실제 오류                                                                         |
| -------- | ------- | ---------------- | --------------------------------------------------------------------------------- |
| 영어     | 494     | 3                | 0 (일주일 → 1 week 로 표기를 바꾼 것)                                             |
| 일본어   | 494     | 30               | 0 (첫 번째·두 번째·한 컵·네 번 → 1回目·2回目·1杯·4回 처럼 한글 수를 숫자로 쓴 것) |
| 중국어   | 494     | 0                | 0                                                                                 |
| 베트남어 | 494     | 3                | 1 (아래)                                                                          |

- 가소콜 문장 전체에 영문 표기(Gasocol)만 들어 있고 한글은 남아 있지 않다(2026-10-30 수정).
- 발견 1건: 베트남어 `A제 1포와 B제 1포를 1L 통에 넣어요.`가 `1 gói A số 1 và 1 gói B số 1`(뜻 없는 "số 1"이 붙음)로 되어 있었다. `Cho 1 gói thuốc A và 1 gói thuốc B vào bình 1L.`로 고쳤다.
- 이 검사는 숫자와 약 이름 표기만 본다. "먹는다/먹지 않는다" 같은 뜻의 반대나 빠진 경고는 잡지 못하므로 2번 역번역 검사가 필요하다.

## 2. 역번역 검사 (다음에 할 일)

번역문을 다시 한국어로 바꿔서 원문과 뜻을 비교하는 표를 이 문서에 추가한다. 형식:

| 원래 한국어 | 언어 | 다시 한국어로 | 뜻 같음? O/X |
| ----------- | ---- | ------------- | ------------ |

X인 것은 표 맨 위에 따로 모은다.

## 4. 위내시경 수업 (2026-10-30)

- 위내시경 수업(`public/lessons/gastroscopy.html`)의 화면 글자·읽어 주는 목소리를 5개 언어(ko/en/ja/zh/vi)로 보여 준다. 글자는 `src/lib/gastro-lesson.ts`가 원문이고, 번역은 위 파일과 같은 `translations/*.json`에 들어 있다.
- 장면 14개 × 5개 언어 × 휴대폰(수업 칸 358px)·PC(1280px) = 140개 상태를 자동 점검해 글자 잘림·겹침·한국어 남음이 0개임을 확인했다(AI 번역이며 원어민 검수는 아직 없음).
- 앞뒤 문맥이 없는 짧은 말(장면 이름표)은 번역이 어색해 몇 문장을 json에서 직접 고쳤다. `npm run translate:build`는 이미 있는 번역을 건드리지 않으므로 그대로 남는다.
