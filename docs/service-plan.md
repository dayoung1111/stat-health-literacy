# S.T.A.T 서비스 기획

건강문해력 격차를 줄이는 AI 병원 안내문 변환 서비스. 병원에 판매하고, 간호사와 환자가 쓴다.
EMR 연결은 하지 않는다.

## 앱 구조: 앱 하나, 문 두 개

환자와 의료진이 같은 첫 화면(/)을 본다. 환자는 큰 버튼으로, 의료진은 맨 아래 출처처럼 작은 글씨로 들어간다.

### 공통 첫 화면(/)

- 맨 위: 왼쪽에 S.T.A.T 로고 작게, 오른쪽에 언어 선택
- 가운데: "어려운 병원 안내문, 쉽게 알려 드릴게요"를 화면에서 가장 크게
- 큰 버튼은 "환자로 들어가기" 하나만 (파란색, 크게)
- 그 아래: "번호를 모르면 병원에 전화"
- 맨 아래 출처(footer)처럼 작은 회색 글씨: "© ○○병원 · S.T.A.T" 아래 밑줄 "의료진 로그인"

### 들어가는 길

- 환자로 들어가기 → 교육 번호 6자리 → 생년월일 6자리 → 환자 화면
- 문자 링크(/p/코드)로 온 환자는 교육 번호 단계를 건너뛰고 바로 생년월일 단계로
- 의료진 로그인 → 아이디·비밀번호 → 의료진 화면(/staff)
- 두 번째부터는 첫 화면을 건너뛴다: 환자는 7일 자동 로그인으로 바로 홈, 의료진은 로그인 유지
- 로그인 시 역할(환자/의료진)을 저장하고 서버에서 매번 확인. 환자는 의료진 화면에 못 들어간다. 환자가 의료진 주소를 직접 입력해도 서버가 막는다

## 의료진 화면 (클릭 3번 + 입력 2칸)

1. 검사 고르기: 큰 버튼(대장내시경, 위내시경, 퇴원 교육, 수술 동의서). 누르면 바로 다음
2. 나이대 선택(10~50대 / 60대 / 70대 이상) → 설명 단계 자동 추천(보통/쉬움/아주 쉬움). 언어(한국어, English, 中文, Tiếng Việt), 큰 글씨·보호자 함께·발달장애 체크는 선택
3. 검사일 + 환자 생년월일 입력 → [코드 발급]
4. 6자리 코드, 링크 복사, 다음 환자 버튼. 코드는 7일 뒤 만료
5. 내가 발급한 코드 목록(이름 없이 코드로만)과 코드별 티치백 결과(어떤 질문을 틀렸는지, 어디서 "헷갈려요"를 눌렀는지)

## 환자 화면 (휴대폰, 글씨 18px 이상, 큰 버튼)

1. 생년월일 확인 → 병원명·검사명·검사일 표시
2. 홈: 검사일 기준 "지금 할 일" 카드 + 버튼(안내문 전체 보기, 이해 확인하기, 위험 신호)
3. 쉬운 안내문: 의료진이 정한 단계·언어로. 문단마다 "헷갈려요" 버튼, 괄호에 원래 의학 용어
   - 또박이 안내 영상: 캐릭터 '또박이'가 같은 안내문을 자막·음성으로 설명한다. 안내문·티치백과 같은 데이터를 써서 내용이 달라지지 않게 한다
4. "헷갈려요" → 그 부분만 한 단계 더 쉽게 다시 설명
5. 티치백 질문 3개 → 틀리면 그 부분만 다시 설명 → 같은 내용을 다른 질문으로 다시 확인 → 이해 완료
6. 결과는 의료진 화면에 자동 반영
7. 위험 신호 화면: 병원 전화 버튼
8. 외국인: 선택한 언어 + 쉬운 한국어 나란히
9. 한 번 들어오면 7일 자동 로그인, 언어·글씨 크기는 환자가 바꿀 수 있음

## 쉬운 말 변환 기준

- 어려운 말은 쉬운 말로, 괄호에 원래 용어
- 한 문장에 한 가지, 해야 할 일은 번호 순서
- 숫자·시간·약 이름은 절대 바꾸지 않기
- 원문에 없는 내용 추가 금지
- 위험 신호는 따로 강조
- 맨 아래 "정확한 내용은 의료진에게 확인하세요"

## 보안

- 환자 이름, 등록번호, 전화번호는 받지 않는다
- 비밀번호와 생년월일은 암호화 저장
- 환자 코드+생년월일 5번 틀리면 잠김
- 의료진은 자기가 발급한 코드만 본다
- API 키는 .env에만, GitHub에 올리지 않는다
- AI 변환은 의료진만 사용
