## 1. 목표와 요구사항

- 사용할 사람과 해결할 문제: 간호사가 환자에게 쉬운 병원 안내문을 코드로 전달하고, 환자는 휴대폰으로 읽고 이해했는지 확인한다. 건강문해력 격차를 줄인다.
- 필요한 기능: 공통 첫 화면, 환자 입장(코드+생년월일), 의료진 로그인, 코드 발급, 쉬운 안내문·"헷갈려요"·티치백·위험 신호, 의료진 결과 확인.

## 2. 포함·제외 범위

### 꼭 (시연에서 실제로 동작)

- 공통 첫 화면(/), 환자 입장(/p → /p/코드), 의료진 로그인(/staff)
- 역할 확인: 환자는 의료진 화면 접근 불가, 의료진은 자기가 발급한 코드만 조회
- 의료진: 검사 선택 → 나이대로 단계 자동 추천 → 검사일·생년월일 → 코드 발급·링크 복사·7일 만료 → 내 코드 목록·코드 상세
- 환자: 본인 확인 → 홈(지금 할 일) → 쉬운 안내문·"헷갈려요" → 티치백 3문제·틀리면 다시 설명·다른 질문 → 이해 완료 → 위험 신호·전화 버튼
- 보안 기본: 5번 틀리면 잠김, 비밀번호·생년월일 해시 저장, 이름·등록번호·전화번호 미수집, 7일 자동 로그인
- 휴대폰 화면, 환자용 글씨 18px 이상
- 시연 데이터: 의료진 계정 1개, 대장내시경 안내문(보통/쉬움/아주 쉬움), 코드 1개(생년월일 590312)

### 여유 있으면

- 의료진이 누르는 AI 실시간 변환(숫자·약 이름 변경 자동 검사 + 의료진 확인 후 발급)
- 외국어 + 쉬운 한국어 나란히 보기(English 우선), 선택한 언어를 다음 화면까지 유지
- 큰 글씨·보호자 함께 옵션, 환자가 직접 언어·글씨 크기 변경
- 위내시경·퇴원 교육·수술 동의서 안내문, 종이 출력, 듣기(음성)

### 발표로만

- 병원 판매 구조와 여러 병원 관리, EMR 미연결 이유(개인정보 최소 수집)
- 中文·Tiếng Việt 안내문 품질 검증, 발달장애 맞춤 모드

## 3. 화면·사용 흐름

- 첫 화면(/): 왼쪽 위 작은 로고, 오른쪽 위 언어 선택, 가장 큰 문구 "어려운 병원 안내문, 쉽게 알려 드릴게요", 파란 큰 버튼 "환자로 들어가기" 하나, 그 아래 "번호를 모르면 병원에 전화", 맨 아래 작은 회색 "© ○○병원 · S.T.A.T"와 밑줄 "의료진 로그인".
- 환자: 첫 화면 → /p(교육 번호 6자리) → /p/코드(생년월일 6자리) → 환자 홈. 문자 링크로 오면 /p/코드에서 시작. 두 번째부터는 7일 자동 로그인으로 바로 홈.
- 의료진: 첫 화면 → /staff(아이디·비밀번호) → 의료진 화면. 로그인 유지.
- 화면 상태: 번호·생년월일 오류, 5번 실패 잠김, 만료된 코드, 로딩, 권한 없음 안내.
- UI/UX·KRDS: 사용자가 준 화면 그림 3장(첫 화면·환자 P1~P10·의료진 ①~⑥)을 기준으로 한다. KRDS는 필요 시 선택적으로 참고한다.

## 4. 현재 구조와 구현 방향

- 기존 코드·DB·설정 확인 결과: Next.js 화면 틀, Prisma + Supabase 연결 코드, `User` 모델(이메일·이름)만 있다. 로그인·세션·AI 연결은 없다. `.env`와 `node_modules`가 없고 마이그레이션 기록도 없다.
- DB 분석·필요한 모델 변경(예정, 승인 전): 병원, 의료진 계정(기존 `User` 확장), 안내문(검사·단계·언어·문단), 티치백 질문, 환자 코드(만료일·실패 횟수), 로그인 세션(역할), 결과 기록("헷갈려요"·정답 여부).
- DB 대상 환경·기존 데이터 보존: 새 Supabase 프로젝트를 쓸 예정이며 아직 확인하지 않았다.
- 인증 방향(제안, 승인 전): 이메일 가입이 없으므로 새 패키지 없이 Node.js 기본 암호화(scrypt) + DB 세션 + httpOnly 쿠키로 의료진·환자를 같은 방식으로 처리한다. 화면마다 서버에서 역할을 확인한다.
- "헷갈려요"·다시 설명·재확인 질문은 코드 발급 시(의료진 동작) 미리 만들어 저장한다. 환자 동작으로 AI를 호출하지 않는다.
- 시연 안내문은 AI로 만든 뒤 작성자(간호학과)가 검수해 넣는다.
- 날짜: 검사일·생년월일은 날짜 전용 값, 만료·생성 시각은 UTC 저장 후 KST 표시([DB 지침](../.agent/database.md#날짜시간과-kst-처리)).
- 폰트: 기존 설정 유지.
- 보안 위험과 대응: 생년월일 6자리는 경우의 수가 적어 해시만으로는 보호가 약하다. 5번 실패 잠김과 7일 만료로 막는다. API 키는 `.env`에만 둔다.

### 협업·중복 검토

- 확인 필요: `npm run dev`가 AGENTS.md 맨 아래에 Next.js 안내 블록을 자동으로 추가함. 유지·끄기는 사용자 결정 대기. 시연용 안내문 의학 내용은 작성자 검수 필요. 시연에서는 어떤 검사를 골라도 코드 482917이 발급된 것으로 보인다.
