# 첫 화면 디자인 (design/home 브랜치, 2026-10-30)

환자용 첫 화면("어려운 병원 안내문, 쉽게 알려 드릴게요" / 환자로 들어가기)의 겉모양만 바꿨다. 가는 곳과 기능은 그대로다.

## 요청 요약

- 이모지 대신 선 아이콘. 색: 청록 #0F6670, 글자 #15262B, 바탕 #F3F6F5, 민트 #DCEDEE.
- 위쪽: S.T.A.T 로고 + 같은 모양 동그란 버튼(소리 / 글자 크게(있으면) / 언어).
- 또박이를 크게(휴대폰은 가운데, PC는 오른쪽) + 청록 말풍선 "안녕하세요, 또박이예요!".
- 청록 큰 버튼 "환자로 들어가기 / 병원에서 받은 번호를 넣어 주세요".
- "이렇게 쓰여요" 카드 3개: 1 번호 넣기 · 2 또박이 수업 · 3 돌발 퀴즈.
- 병원 전화: 전화 아이콘 + 번호를 크게 쓴 카드.
- 의료진 로그인: 테두리 버튼(휴대폰은 아래, PC는 오른쪽 위).
- 충돌 방지: 첫 화면 파일만 고치고, 공통 부품·공통 스타일·설정 파일·demo-guide.ts·기존 계획 파일은 건드리지 않는다.

## 바꾼 것

- `src/app/page.tsx`: 새 배치. 휴대폰은 한 줄(또박이 → 제목 → 들어가기 → 카드 3개 → 전화 → 의료진 로그인), PC(1024px 이상)는 왼쪽 글·버튼, 오른쪽 또박이 두 칸.
- 새 `src/app/home-icons.tsx`: 첫 화면 전용 선 아이콘(소리 켜짐/꺼짐, 언어, 전화, 화살표, 의료진, 카드 3개).
- 새 `src/app/home.css`: 첫 화면 전용 모양. 공통 부품 `SoundToggle`·`Ttobagi`(ttobagi.tsx)는 고치지 않고 그대로 쓰면서, 이 화면에서만 동그란 버튼·선 아이콘·큰 또박이·청록 말풍선으로 보이게 했다. 그래서 소리 켜고 끄기, 또박이 눌러 듣기, 첫 터치 뒤 다음 화면 자동 읽기가 전과 같다.
- 언어: 동그란 지구본 버튼 위에 원래 언어 고르기 칸을 투명하게 겹쳐, 누르면 같은 언어 목록이 뜬다.
- 문구(`src/lib/messages/` 5개 언어 파일의 `home` 부분만): `hello`를 "!"로, `enterHint`를 "번호를 넣어 주세요"로, 카드용 `howTitle`·`how` 추가.
- 글자 크게 버튼: 지금 앱에 그 기능이 없어 넣지 않았다.
- 전화번호 값은 `demo-guide.ts`의 `hospital.phone` 그대로.

## 확인

- 고치기 전과 후 모두 실제 크롬(휴대폰 390x844, PC 1280x800): 환자로 들어가기(/p 이동), 소리(켜짐↔꺼짐 저장), 언어 바꾸기(영어 ↔ 한국어), 의료진 로그인(/staff 이동), 병원 전화(tel:02-0000-0000) 모두 통과. 가로 넘침·잘림·겹침 없음.
- `npm test`, `npm run check`, `npm run build` 통과 뒤 커밋.
